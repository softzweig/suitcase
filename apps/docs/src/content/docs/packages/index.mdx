## Dependency direction

```text
core
  ├── server ── drizzle
  │      └── http/server
  ├── client ── react
  │      ├── upload-queue
  │      └── http
  ├── job-queue
  ├── s3
  └── image-processor
```

`core` has no runtime dependencies beyond Zod and `@noble/hashes`. Adapters depend on `server` or
`client`, never the other way around. A definition never imports an adapter.

## What is private

`@softzweig/suitcase-typescript-config` is a private workspace package with the tsconfig presets. It
is never published and never installed by consumers.
